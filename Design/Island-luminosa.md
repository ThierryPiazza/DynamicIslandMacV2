# Island luminosa — initial concept

Initial icon generated with the built-in image_gen tool. Original PNG is preserved as `Island-luminosa.png`. The app now uses the black and white revision documented in `Island-minimal.md`.

The menu bar uses an independent vector template in `AppDelegate.swift`, with the same capsule, dash and dot. macOS applies the appropriate monochrome appearance.

## Generation prompt

Use case: logo-brand
Asset type: final macOS application icon for Dynamic Island, square 1024x1024 PNG.
Primary request: "Island luminosa": a premium minimal luminous floating black island capsule on a deep electric blue rounded-square tile.
Composition: straight-on, perfectly symmetrical. One rounded-square tile centered, occupying about 86% of the square canvas with generous smooth continuous corners. Actual transparent alpha background outside the tile, including corner cutouts. Inside the tile a large horizontal obsidian-black capsule, centered, width about 65% of tile and height about 22% of tile, with clean smooth semicircular ends. A very thin restrained cyan luminous rim along its bottom edge casts a soft blue glow immediately underneath. Two tiny restrained luminous details inside the capsule, one short icy-blue dash at left and one blue dot at right.
Style: meticulously polished macOS icon, restrained dimensional depth, subtle upper edge reflection, crisp bold silhouette clearly readable at small sizes. Smooth midnight-blue to cobalt tile gradient with gentle cyan light concentrated below the island. Mostly dark upper area. No noisy textures.
Constraints: deliver one isolated finished icon only, not a presentation or mockup. No text, letters, checkmarks, musical notes, extra symbols, devices, frames, grid, or watermark. No broad neon bloom. Background outside rounded tile must be genuinely transparent, never white and never baked checkerboard.
