# Island minimal — current app icon

Created with the built-in image_gen tool, editing `Island-luminosa.png`. The original generated result is preserved in `Island-minimal.png`. All macOS AppIcon slots are downsampled from this PNG with sips, preserving alpha.

The menu bar uses a matching native vector template in `AppDelegate.swift`: solid capsule with transparent dash and dot cutouts. macOS controls its color for light, dark and highlighted appearances.
